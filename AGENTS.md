# ugurmertyasar.github.io

Personal academic website for Ugur Mert Yasar ("Umy"), sixth-year Behavioral
Science PhD candidate at Chicago Booth, on the postdoctoral job market and
applying to the Harvard Society of Fellows.

**Audience:** search committee members and fellowship reviewers, skimming for
about ninety seconds, often on a phone, often on institutional wifi.

**Strategic goal:** move attention from *what has he published* (nothing yet) to
*what has he built* (a 92-society, 44-language survey with ~18,400 participants).
That is an accurate framing, not spin, and every design decision follows from it.

---

## Architecture

Static HTML and CSS. **No build step, no framework, no package manager.** The
files in this repository *are* the site. GitHub Pages serves them directly.

```
index.html          Home: hero and the survey map section
research.html       Working Papers and Work in Progress
teaching.html       Courses TA'd at Booth, copied from the CV's Teaching section
style.css           All styling. Palette variables at the top in :root.
README.md
assets/
    favicon.svg         "UMY" on slate; the browser-tab icon
    cdr.jpg             Research-page photo (Center for Decision Research, by Jason Smith)
    portrait.jpg        900x900 headshot
    cv.pdf              Rendered from the Quarto source (see below)
```

This choice was deliberate. The site has to keep working across several
application cycles with no maintenance, so there is nothing to rot: no
dependencies, no lockfile, no Ruby or Node toolchain. **Do not introduce a build
step, a static site generator, or a JS framework.** If a change seems to require
one, it is the wrong change.

## Design decisions (do not silently reverse these)

**Palette.** Every colour is a CSS variable in `:root` at the top of
`style.css`. White paper `#ffffff`, near-black ink `#1b1b1b`, slate blue accent
`#2f5d74` (also the masthead band), dark footer band. Layout and type were
modelled loosely on the Cultural Dynamics Lab site
(cultural-dynamics-lab.github.io) at Umy's request (October 2026), but slate
rather than that site's crimson so the two do not look identical. **No dark mode**: removed October 2026 so every visitor sees the
same white page.

Two accent variables exist, `--formal` (slate) and `--informal` (olive),
corresponding to the formal/informal institutional axis in Umy's research. They
are currently unused on visible elements, deliberately (see "Do not publish").

**Typography.** Oswald (condensed, uppercase) for headings, labels, nav and
the big numbers; Inter for body text and paper titles. Loaded from Google Fonts.

**Motion.** Confined to the map tooltip and hover fill. Nothing else animates. Decorative
motion reads as portfolio-designer rather than scholar to this audience.

**Survey section is hidden.** The home-page map section has a switch on
`<section class="plate">`: `data-state="hidden"` (current) removes it
entirely; `data-state="soon"` shows the map and a "coming soon" note; `data-state="live"` also reveals the `.when-live` blocks (stats,
caption) drafted underneath. Umy's view: a coverage map alone is not
distinctive, so it goes fully live only with interactive results. Hidden
drafts are still readable in the public source.

**Headings.** The two-tone treatment is not used. Home: the name as h1. Inner
pages: a plain title on a grey `.page-header` band, plain section h2s.

## The coverage map

Inline SVG inside `index.html`, roughly 127 KB, about 46 KB gzipped. It is
inline rather than an `<img>` because an SVG loaded as an image is sealed off
from the page and cannot be styled with CSS variables or made interactive. The
block is fenced with `<!-- MAP -->` comments.

Structure, back to front: `.ocean` (the projected sphere outline, Equal Earth
projection), `.grat` (graticule, meridians every 30 degrees and parallels at
0, +/-30, +/-60), the country paths, then `.edge` (sphere outline stroke).

Each *surveyed* country carries `data-n` (display name), `data-l` (survey
language) and an `aria-label`. Non-surveyed countries carry no name at all, so
hovering them shows nothing (deliberate). `<title>` children were removed
because they produced a second, native browser tooltip on top of ours. If the
map is regenerated, the generator must follow the same rules. Hong Kong, Singapore and Puerto Rico are dot markers because they are
too small to render at this resolution.

Interaction: hover on pointer devices, tap on touch devices, handled by the
script at the bottom of `index.html`.

**Do not hand-edit the path data.** The map is generated by a Python script from
the `world-atlas` `countries-110m.json` topology plus a country-to-language
table. Regenerating it needs both. Ask in the Codex chat rather than editing
coordinates.

## Do not publish

**The repository is public and git keeps deleted files in history. Treat
anything committed as permanently public.**

- **No data.** The 92-society dataset is private until publication. Fieldwork
  metadata (which countries, which languages) is fine; findings are not.
- **No theory exposure.** "Rulebooks and Relationships" is an unpublished theory
  paper. Earlier drafts of the site spelled out its argument in the research
  page introduction; that was removed on purpose. Do not restore it.
- **`_held/enforcement-figure.html`** is an interactive figure demonstrating that
  a single tightness score conflates two dimensions. It lives on Umy's machine
  only and is deliberately not in this repository. Do not commit it. It goes
  live when the paper is published, by pasting the `<figure>` into
  `research.html` and the `<script>` before `</body>`.
- Anything a browser renders, a visitor can download. There is no way around
  this on a static site, which is why the rule above is absolute rather than a
  preference.

## Related project: the CV

Lives separately in `~/Documents/cv/`, not in this repository. Quarto source,
one file producing both a PDF and an HTML version.

```
cv.qmd            The CV content
publications.qmd  Papers only, with a Harvard Society of Fellows running header
cv.css            Styles the HTML output
cv-header.tex     Styles the PDF output (LaTeX preamble)
cv-filter.lua     Lets one source produce both layouts. Do not edit.
```

Render with the Render button in RStudio, or `quarto render cv.qmd`. Note that
`quarto` is not on the shell PATH; RStudio bundles its own copy at
`/Applications/RStudio.app/Contents/Resources/app/quarto/bin/quarto`.

The CV PDF belongs at `assets/cv.pdf` in this repository after each render.

Typography there is Arial throughout, black on white, deliberately different
from the website. `cv-header.tex` uses only fontspec, xcolor and hyperref so a
bare TinyTeX can build it; a missing `.sty` file means TinyTeX's package index
is stale, fixed with `quarto uninstall tinytex && quarto install tinytex`.

One placeholder remains in `cv.qmd`: the dissertation title is marked
`[provisional]{.tk}` and renders underlined. Remove the marker once settled.
